# CHP-Angola Corretores de Seguros

Website oficial da **CHP-Angola Corretores de Seguros** — corretora independente em Angola, especializada em seguro automóvel obrigatório, saúde, vida e património.

![CHP-Angola](icons/og-image.jpg)

## ✨ Funcionalidades

- 🎨 Design premium com animações cinematográficas
- 🚗 **Simulador interativo** de seguro automóvel (3 passos)
- 🌓 **Dark mode** com persistência
- 📱 **PWA** — instalável como app nativa
- 🎤 **Voice input** no formulário (Web Speech API)
- 💬 **Chatbot** assistente em português
- 🌐 **Three.js 3D** — esfera de partículas douradas
- ⚡ **Performance otimizada** — CSS + JS puro, sem framework
- ♿ **Acessibilidade** — ARIA, teclado, prefers-reduced-motion
- 📊 **Tracking** — Google Analytics 4 + Meta Pixel
- 📈 **Contadores em tempo real** — prova social

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (variáveis, grid, flexbox, backdrop-filter)
- JavaScript vanilla (ES6+)
- [Three.js](https://threejs.org/) — animação 3D
- [Lottie](https://airbnb.io/lottie/) — animações vetoriais
- [Formspree](https://formspree.io/) — backend do formulário
- [Inter + Playfair Display](https://fonts.google.com/) — tipografia
