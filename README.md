## 📌 Sobre o Projeto

Sistema digital completo desenvolvido para a CHP-Angola — corretora de seguros independente em Angola. Inclui website público premium, simulador interativo de seguros, backend próprio com base de dados, painel administrativo e aplicação PWA instalável.

## ✨ Funcionalidades Principais

### 🌐 Website Público
- Landing page premium com animação 3D (Three.js)
- Simulador interativo de seguro automóvel (3 passos)
- Dark mode com persistência
- Chatbot assistente em português
- Voice input no formulário (Web Speech API)
- Secções completas: Serviços · Sobre · FAQ · Contactos
- Botão WhatsApp flutuante
- Contadores de prova social em tempo real
- Cursor personalizado dourado
- Totalmente responsivo (mobile / tablet / desktop)

### 🔐 Painel de Gestão
- Autenticação HTTP Basic
- Ver, filtrar e pesquisar leads
- Marcar como contactado / desmarcar
- Eliminar leads (com confirmação)
- Exportação CSV (compatível com Excel)
- Estatísticas em tempo real (6 indicadores)
- Paginação inteligente
- Interface dark theme premium

### 🎁 Funcionalidades Avançadas
- **Widget de Ações Rápidas** — menu flutuante com 5 atalhos
- **Agendamento com Calendário** — download `.ics` + Google Calendar
- **Push Notifications** — alertas em tempo real no telemóvel
- **Alertas de Leads Urgentes** — classificação automática por palavras-chave e tipo
- **App PWA** — instalável como app nativa no Android / iOS / Desktop
- **Modo Offline** — funciona sem internet com cache inteligente
- **Dark Mode** — alternância claro/escuro com persistência

### 🔍 SEO + Performance
- Meta tags completas (SEO + Open Graph + Twitter Card)
- Schema.org (rich snippets Google)
- Sitemap.xml + robots.txt
- Google Analytics 4 configurado
- Meta Pixel (Facebook / Instagram Ads)
- Performance otimizada (lazy loading, compressão, preconnect)
